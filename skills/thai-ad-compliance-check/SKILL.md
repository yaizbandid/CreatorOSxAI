# thai-ad-compliance-check

ตรวจงานเขียนโฆษณา/รีวิวสินค้าภาษาไทย **ก่อนโพสต์** ใช้กับ Neptune Story, Pierre Cardin และช่อง Affiliate ของ Boss
ไม่ต้องสมัครอะไร ไม่ต้องใช้ key ทำงานด้วยการอ่านข้อความแล้วตรวจตามรายการด้านล่าง

> ข้อจำกัด: นี่คือตัวช่วยคัดกรองเบื้องต้น ไม่ใช่คำปรึกษากฎหมาย กฎ อย./สคบ./ก.ล.ต. และนโยบายแพลตฟอร์มเปลี่ยนได้
> ถ้าคำไหนกำกวมหรือเสี่ยงสูง ให้ติดธง "ให้คนตรวจซ้ำ" ห้ามฟันธงว่า "ผ่าน 100%"

## วิธีใช้
1. รับข้อความ (สคริปต์พูด, แคปชัน, ชื่อคลิป, ข้อความบนภาพ) + ระบุหมวดสินค้า ถ้า Boss ไม่บอก ให้เดาจากข้อความแล้วบอกว่าเดาหมวดอะไร
2. ไล่ตรวจ 4 ชุดด้านล่าง ชุดที่ 1 และ 4 ตรวจเสมอ ชุดที่ 2-3 ตรวจตามหมวด
3. รายงานเป็นตาราง: `ประโยค/คำที่เจอ | ปัญหา | ระดับ (🔴 ต้องแก้ / 🟡 ควรปรับ) | คำที่ปลอดภัยกว่า`
4. ปิดท้ายด้วยเวอร์ชันที่แก้แล้ว 1 ชุด และบรรทัดสรุป: 🟢 พร้อมโพสต์ / 🟡 แก้แล้วโพสต์ได้ / 🔴 ต้องให้คนตรวจซ้ำ
5. ห้ามแก้ข้อเท็จจริงเอง (ตัวเลข ส่วนผสม เลข อย.) ถ้าไม่มีหลักฐาน ให้ถาม Boss

## ชุดที่ 1 ใช้ทุกหมวด
- **คำอ้างเกินจริง/การันตี**: "ดีที่สุด", "อันดับ 1", "100%", "ชัวร์", "หายขาด", "ไม่มีผลข้างเคียง" → 🔴 ถ้าไม่มีหลักฐานอ้างอิง ปรับเป็น "หลายคนชอบ", "จากที่ลองใช้ ผมรู้สึกว่า…"
- **ผลลัพธ์พร้อมตัวเลขเวลา**: "ขาวใน 7 วัน", "ลด 5 โล ใน 1 สัปดาห์" → 🔴
- **รีวิวปลอม/ประสบการณ์ที่ไม่เคยใช้จริง**: ถ้าสคริปต์เขียนว่า "ใช้มา 3 เดือน" ให้ถาม Boss ว่าจริงหรือไม่ → 🔴 ถ้าไม่จริง
- **ราคา/โปรโมชัน**: ต้องตรงกับหน้าสินค้าตอนโพสต์ ใส่ "ราคา ณ วันที่…" ถ้าโปรเปลี่ยนบ่อย → 🟡
- **เปรียบเทียบ/พาดพิงคู่แข่งโดยระบุชื่อ** แบบดูหมิ่นหรือไม่มีหลักฐาน → 🔴

## ชุดที่ 2 อาหารเสริม / สุขภาพ / อุปกรณ์การแพทย์ (หมวดเสี่ยงสุด)
อาหารเสริมห้ามอ้างว่า "รักษา/บำบัด/ป้องกันโรค" เด็ดขาด
- 🔴 อ้างรักษาโรค: "รักษา/หายจาก/ต้าน/ป้องกัน" + ชื่อโรค (มะเร็ง เบาหวาน ความดัน หัวใจ ไต ตับ ภูมิแพ้ โควิด ฯลฯ), "แทนยา", "เลิกกินยาได้"
- 🔴 อ้าง "เสริมภูมิ/ภูมิคุ้มกัน" แบบฟันธงหรือทันที, "แก้ที่ต้นเหตุ", "ล้างสารพิษ"
- 🔴 ลดน้ำหนักแบบระบุตัวเลข+เวลา, "ไม่ต้องคุมอาหาร/ไม่ต้องออกกำลังกาย"
- 🟡 ต้องแสดงเลข อย. ของผลิตภัณฑ์จริง ถ้าไม่มีเลขในข้อมูลที่ได้รับ ให้เตือนให้ Boss ตรวจกล่องสินค้า
- ใช้แทนได้: "ช่วยเสริมสารอาหาร", "เป็นส่วนหนึ่งของการดูแลสุขภาพ", "ควรปรึกษาแพทย์/เภสัชกรก่อนใช้ ถ้ามีโรคประจำตัว", "ผลลัพธ์แต่ละคนไม่เหมือนกัน"

## ชุดที่ 3 เครื่องสำอาง / สกินแคร์
- 🔴 อ้างผลทางการแพทย์หรือเปลี่ยนโครงสร้างผิว: "รักษาสิว/ฝ้า/กระ", "ลบรอยแผลเป็นถาวร", "ผิวขาวถาวร", "ซ่อมเซลล์ผิว", "เข้าสู่กระแสเลือด"
- 🔴 อ้าง "ปลอดภัย 100%", "ไม่แพ้แน่นอน", "อ่อนโยนทุกสภาพผิว" โดยไม่มีหลักฐาน
- 🟡 เลขจดแจ้ง อย. เครื่องสำอาง ควรมีให้ตรวจได้
- ใช้แทนได้: "ช่วยให้ผิวดูกระจ่างใส", "ช่วยให้ผิวรู้สึกชุ่มชื้น", "ช่วยให้สิวดูแห้งลง (ไม่ใช่รักษา)", "แนะนำทดลองที่ท้องแขนก่อน"

## ชุดที่ 3.5 การเงิน / ลงทุน / คริปโต (ถ้าเกี่ยวข้อง)
- 🔴 ผลตอบแทนการันตี, "กำไรแน่นอน", "ไม่มีความเสี่ยง", ตัวเลขผลตอบแทนต่อเดือน/ปี แบบชวนเชื่อ
- 🔴 ชวนลงทุนโดยไม่ใช่ผู้ได้รับอนุญาต หรือแอบอ้างหน่วยงานรัฐ/ธนาคาร
- 🟡 ต้องมีคำเตือน "การลงทุนมีความเสี่ยง ผู้ลงทุนควรศึกษาข้อมูลก่อนตัดสินใจ" และไม่ใช่คำแนะนำส่วนบุคคล
- ถ้าเป็นงานเทรด/คริปโตของ Boss เอง ให้ใช้เฉพาะข้อนี้ ไม่ต้องใช้ชุด Neptune/Pierre

## ชุดที่ 4 การเปิดเผยความเป็นโฆษณา/Affiliate (ตรวจเสมอ)
- 🟡 ต้องบอกชัดว่ามีค่าคอมมิชชัน/สปอนเซอร์ เช่น "#โฆษณา", "มีลิงก์ Affiliate ผมได้ค่าคอมเล็กน้อย" ต้องเห็นได้ในคลิปหรือบรรทัดแรกของแคปชัน ไม่ใช่ซ่อนท้ายสุดหลัง hashtag
- 🟡 ใช้ฟีเจอร์ "branded content/paid partnership" ของแพลตฟอร์มถ้ามี (Facebook/IG/TikTok/YouTube) และติ๊กว่ามีเนื้อหาที่สร้างด้วย AI ถ้าใช้เสียง/ภาพสังเคราะห์
- 🟡 ห้ามใช้บุคคลมีชื่อเสียงหรือผู้เชี่ยวชาญ (หมอ/เภสัชกร) ที่ไม่ได้ให้การรับรองจริง
- 🟡 ภาพก่อน-หลังต้องเป็นของจริงและระบุว่าเป็นผลเฉพาะบุคคล

## รูปแบบคำตอบ (สั้น)
```
หมวดที่เดา: ...
พบ N จุด (🔴 x / 🟡 y)
| ประโยค | ปัญหา | ระดับ | แก้เป็น |
เวอร์ชันแก้แล้ว: ...
สรุป: 🟢/🟡/🔴 + สิ่งที่ Boss ต้องตรวจเอง (เลข อย., หลักฐาน, รีวิวจริง)
```

## กฎของ Skill นี้
- เขียนใหม่จากความรู้กฎทั่วไป ไม่ได้คัดลอกโค้ดหรือรายการคำจาก repo ใดๆ
- ห้ามอวยว่า "ผ่านแน่นอน" ให้บอกความเสี่ยงที่เหลือเสมอ
- ถ้าพบคำเสี่ยงที่ไม่อยู่ในรายการ ให้ใช้หลัก: "ข้อความนี้ทำให้คนเข้าใจว่าสินค้ารักษา/การันตีผลหรือไม่" ถ้าใช่ ให้ติดธง
